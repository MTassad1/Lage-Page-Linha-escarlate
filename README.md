## 📖 Sobre o projeto

A **Linha Escarlate** é uma marca fictícia de roupas de alfaiataria e tecidos de luxo, pensada para um público de alto poder aquisitivo. O site apresenta a marca, mostra uma vitrine de produtos e simula a experiência de compra (filtros, carrinho e newsletter).

O projeto foi criado **como exercício de estudo de desenvolvimento web**, com o objetivo de praticar HTML, CSS e JavaScript na construção de uma página completa, com identidade visual própria e foco em design minimalista.

> ⚠️ Projeto **fictício**: os produtos, preços e a marca não existem de verdade e nenhuma compra real é processada.

---

## ✨ Funcionalidades

- **Banner principal** com chamada de destaque e botões de ação
- **Vitrine de produtos** com 8 peças (terno, blazer, camisa, casaco, calças e malha)
- **Filtro por categoria:** Todos, Masculino e Feminino
- **Carrinho de compras** com botão "Adicionar ao carrinho" e total estimado
- **Seção "Nossa perspectiva"** apresentando os valores da marca
- **Newsletter** com campo de e-mail
- **Navegação por âncoras** entre as seções da página
- **Rodapé** com links de atendimento, trocas e políticas

---

## 🎨 Identidade visual

- **Estilo:** minimalista, elegante e atemporal, com muito espaço em branco
- **Paleta:** base neutra (preto, branco e tons de cinza), com o **vermelho escarlate reservado apenas ao nome da marca**
- **Fotografias:** predominância de preto e branco, com foco em tecidos, alfaiataria e detalhes
- **Tom de voz:** discreto e sofisticado (ex.: *"O luxo está naquilo que se percebe de perto."*)

## 🚀 Como rodar o projeto localmente

1. **Clone o repositório**
   ```bash
   git clone https://github.com/mtassad1/Lage-Page-Linha-escarlate.git
   ```
2. **Entre na pasta**
   ```bash
   cd Lage-Page-Linha-escarlate
   ```
3. **Abra o `index.html`** no navegador (duplo clique) ou use a extensão **Live Server** do VS Code.

Não é necessário instalar nada: o projeto usa apenas HTML, CSS e JavaScript puros.
